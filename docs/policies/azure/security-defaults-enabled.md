# Ensure That Security Defaults Are Enabled in Microsoft Entra ID

| Provider | Category |
| -------- | -------- |
| Azure    | Identity and access management |

## Description

This control evaluates `msgraph_update_resource` resources targeting `policies/identitySecurityDefaultsEnforcementPolicy`, ignoring URL case and surrounding slashes. It requires `body.isEnabled` to be the boolean `true`. A false, missing, null, or string value does not meet the control.

Security defaults provide a baseline of identity protections in Microsoft Entra ID. This control requires the configured Microsoft Graph update to enable those protections.

Requires `Microsoft/msgraph >= 0.5.0, < 1.0.0`. Enforcement defaults to `advisory` and is configurable through `security-defaults-enabled-enforcement-level`.

This rule is covered by the [security-defaults-enabled](../../../policies/azure/iam/security-defaults-enabled.policy.hcl) policy.
