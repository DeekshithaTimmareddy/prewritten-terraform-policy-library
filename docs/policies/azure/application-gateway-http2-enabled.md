# Ensure that HTTP2 is Enabled on Application Gateway

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control implements CIS Azure Foundations Benchmark v6.0.0 control 7.13.

This control checks whether Azure Application Gateways enable HTTP2 with `http2_enabled = true`. HTTP2 supports more efficient client connections through features such as multiplexing and header compression.

AzureRM defaults this setting to `false`, so HTTP2 must be explicitly enabled. Listener protocol and SKU tier do not exempt a gateway from this check, and the older `enable_http2` alias is not used.

**Enforcement note:** unresolved values are deferred until the setting is known. Enabling HTTP2 does not independently prove that TLS is securely configured.

Enforcement defaults to `advisory` and can be configured with the `application-gateway-http2-enabled-enforcement-level` input.

This rule is covered by the [application-gateway-http2-enabled](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/network/application-gateway-http2-enabled.policy.hcl) policy.
