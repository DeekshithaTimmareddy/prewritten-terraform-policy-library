# Ensure that Application Gateway Uses the WAF_v2 Tier and an Enabled WAF Policy

| Provider | Category |
| -------- | -------- |
| Azure    | Network security |

## Description

This control implements CIS Azure Foundations Benchmark v6.0.0 control 7.10.

This control checks whether Azure Application Gateways use the `WAF_v2` SKU tier and reference a gateway-level Web Application Firewall policy. A WAF helps protect web applications against common application-layer attacks.

The policy checks `sku.tier`, requires a valid WAF policy ARM ID in `firewall_policy_id`, and rejects a matching plan-visible policy when `policy_settings.enabled` is `false`. It does not add a requirement to use Prevention rather than Detection mode.

**Enforcement note:** unknown values are deferred. A reference to an external WAF policy verifies only the reference format, not whether that external policy is enabled. Validate its deployed settings separately.

Enforcement defaults to `advisory` and can be configured with the `application-gateway-waf-enabled-enforcement-level` input.

This rule is covered by the [application-gateway-waf-enabled](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/azure/network/application-gateway-waf-enabled.policy.hcl) policy.
